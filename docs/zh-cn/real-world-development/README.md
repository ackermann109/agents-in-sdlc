在真实的软件开发生命周期中使用 GitHub Copilot：借助贴近实际的场景、完整应用和共享待办事项，迭代规划更改、编写代码、测试行为、审查拉取请求并使用代理管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为开发者主题的棋盘游戏提供众筹服务。团队的待办事项已作为 GitHub 议题创建，可供你领取，其中既有筛选和分页等功能，也有无障碍和编码规范等质量改进。

## 选择工作环境

GitHub Copilot 可以配合你使用的环境工作。选择适合自己的开发环境；每个研讨会都有单独的设置流程，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用 GitHub Copilot 命令行界面（CLI）代理式助手，体验 Plan 和 Autopilot 模式、指令、技能、自定义代理、Playwright 模型上下文协议（MCP）、Agent Merge 和实用斜杠命令。

### [GitHub Copilot app][app]

在桌面应用中运行并行代理会话、切换会话模式、协作使用画布，以及管理 GitHub 议题和拉取请求。

### [GitHub Copilot 云智能体][cloud]

将 GitHub 议题分配给异步代理，引导代理完成工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot Chat 代理模式、MCP 服务器和自定义代理，无需离开编辑器。
